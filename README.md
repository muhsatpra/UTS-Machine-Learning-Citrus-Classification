# UTS-Machine-Learning-Citrus-Classification

Projek ini mengelompokkan buah citrus antara :

- Orange
- Grape

menggunakan 3 machine learning algorithms:

1. Decision Tree
2. Naive Bayes
3. Support Vector Machine (SVM)

## Dataset

File used:

- `citrus.csv`

Fitur:

- diameter
- weight
- red
- green
- blue

Target:

- name (orange / grape)

## Extension tools : 

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Hasil

| Algorithm | Accuracy |
|----------|----------|
| Decision Tree | 93.84% |
| Naive Bayes | 92.08% |
| SVM | 92.56% |

Best model: **Decision Tree**
